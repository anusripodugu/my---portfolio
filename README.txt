FILES IN THIS FOLDER
- index.html: complete website content
- style.css: dark modern theme and responsive layout
- script.js: mobile navigation, current year, and back-to-top button
- profile-photo.jpeg: your portrait shown in the Home section
- resume.pdf: resume linked from the website

HOW TO OPEN THE WEBSITE
1. Download the ZIP and choose Extract All.
2. Open the extracted my-portfolio folder.
3. Keep all files listed above together in this same folder.
4. Open Chrome or Microsoft Edge.
5. Press Ctrl+O, select index.html, and click Open.

HOW TO PUBLISH WITH GITHUB PAGES
1. Create a PUBLIC GitHub repository named my-portfolio.
2. Upload the files inside this folder directly into the repository root, not inside another nested folder.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select branch main and folder /(root), then click Save.
6. Wait for deployment and open the URL shown on the Pages settings screen.

IMPORTANT NOTES
- Keep profile-photo.jpeg beside index.html; the page uses this exact filename.
- Keep style.css, script.js, and resume.pdf beside index.html too.
- Project links currently point to your GitHub profile. Replace them with individual project repository URLs when available.
- Review all details and make sure they are accurate before publishing.
- If you do not want your resume publicly accessible, remove resume.pdf and the View My Resume link before publishing.
